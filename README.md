# 知味厨房 · 智能电子菜谱（Web / PWA）

按《电子菜谱需求规格说明书 V1.0》实现的可交互 Web 应用，支持桌面与移动端（响应式 + PWA，可安装到手机桌面当 App 使用）。

**在线访问（GitHub Pages，push 到 main 自动部署）**：https://pikaqim.github.io/zhiwei-kitchen/

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 电子菜谱 | 首页浏览 / 搜索（菜名、食材）/ 来源与菜系筛选 / 结构化详情页（步骤、火候、小贴士）|
| 智能解析 | 粘贴菜谱文本 → 抽取菜名 / 食材 / 步骤 → 回填编辑器（UC-01）|
| AI 生成菜谱图 | 封面图 / 整批步骤图，风格（摄影 / 插画 / 简笔画）、画幅、多候选、重绘、采用（UC-03）|
| AI 生成烹饪视频 | 分镜脚本生成与编辑 → 异步任务（排队 → 逐镜生成 → 拼接字幕 → 成功），含镜级自动重试演示（UC-04）|
| 自定义上传 | 实拍视频上传（模拟分片 / 转码 / 机审）→ 挂载到菜谱；菜谱文档导入（UC-05 / U-01）|
| 配额与任务中心 | 每日图片 10 / 视频 1 / 解析 20 次配额，任务账本记录类型、成本、耗时、状态 |
| 合规 | AI 生成内容角标「AI 生成」、详情页食品安全免责声明、上传版权承诺勾选 |

## 运行

纯静态站点，无需构建：

```bash
cd ai2
python -m http.server 8080
# 打开 http://localhost:8080
```

> Service Worker 仅在 `localhost` 或 HTTPS 下注册；直接双击 `index.html`（file://）功能可用但无 PWA 缓存。

## 目录结构

```
ai2/
├── index.html            # 应用外壳（导航 / 弹窗 / 挂载点）
├── css/style.css         # 全部样式（响应式：>900px 双栏，≤640px 底部导航）
├── js/
│   ├── data.js           # 种子数据 + 全局状态（localStorage 持久化）
│   ├── services.js       # 服务层：配额 / 任务账本 / AI 与上传流水线（当前为模拟实现）
│   └── app.js            # hash 路由 + 视图渲染 + 交互
├── manifest.webmanifest  # PWA 清单
├── sw.js                 # Service Worker（应用外壳 cache-first）
├── icons/                # 应用图标（SVG）
└── docs/                 # 需求文档与验收报告
```

## 诚实的范围说明（重要）

当前所有"AI 能力"（文本解析、文生图、文生视频）与"视频上传 / 转码 / 机审"均为**前端本地模拟**，
用于验证产品流程与交互，不调用任何真实模型 API，也没有后端。

接入真实服务时只需替换 `js/services.js` 中的各 `*Pipeline` 函数为 HTTP 调用
（接口形状已在函数注释中标明：入参、回调、返回值），页面层与状态层无需改动。
对应的后端设计见 `docs/` 中的需求规格说明书（数据库 DDL、API 草案、生成网关规范）。

## 部署

GitHub Pages 分支模式：`main` 分支根目录即站点，每次 push 自动触发 Pages 重新构建与发布（无需额外 CI 配置）。
